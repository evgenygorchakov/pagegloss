PageGloss

Settings

Make your local text workspace feel like yours.

llama.cpp

Llama app and the browser on the same Windows computer use http://127.0.0.1:9931. Start the model's chat/server in Llama app. For another address, the extension will ask for access. If the server reports HTTP 403, allow with the server's --cors-origins option.

Web search

Off by default. Without web search, Ask freely and Text workspace use the provided text and the model's knowledge. Enable it after setting up SearXNG. Searches go through your SearXNG server; answers use your selected llama.cpp model. No API key is needed. SearXNG must allow JSON search (search.formats: [html, json] in settings.yml). Save checks SearXNG before enabling search or changing its address while search is on. Check runs a sample search without enabling it. Answers use search excerpts, not full page downloads. Requires a model with tool support and a context of at least 8192, set in llama.cpp.

Requests

Set context length in Llama app or with llama serve -c. The extension uses the context available to one server slot and shows token usage in the popup and next to answers. Start with 1 parallel request; increasing it requires enough memory and server slots (--parallel).
Advanced: custom system prompt

Leave empty for the built-in prompt (shown in gray). {targetLang} is replaced with the language name. The model must return JSON {"translations": [...]}: the response format is enforced by a schema, but it is better to mention it in the prompt too.

Video dubbing

Speech synthesis server: tools/silero on Windows, the systemd service from sup/optional/voice on Linux. Dubbing is always in Russian, the translation language doesn't affect it.

Original volume, speech speed-up and Russian subtitles are in the menu next to the “Translate” button in the YouTube player.
